借別人的 IP 出口（SSH SOCKS）＋一個踩雷的教訓
讓 worker 爬 Yahoo 的 curl 走 SSH SOCKS5，從一台雲端 VM 的 IP 出去（技術正確、可重用）。 但我們原本是想用它「繞 rate limit」——實測後發現搞錯病因：真凶是 Yahoo 邊緣間歇 500，解方是重試而非換 IP。
